# Odaseva

> Enterprise data security, backup, and governance platform purpose-built for large, complex
> Salesforce environments: backup and recovery, archiving, seeding and anonymization/masking,
> encryption and key management, privacy and data-residency controls, and data governance for
> regulated enterprises. Odaseva runs as a Salesforce-hosted application and sells to
> enterprises through a contact-sales motion.
>

> (https://www.odaseva.com/llms.txt returned HTTP 404 on 2026-08-17). Everything below was
> either fetched from an Odaseva-controlled host or read from a first-party package Odaseva
> published to npm. Generated: 2026-08-17.

## What an agent can and cannot do here

- There is NO public machine-readable contract. No OpenAPI, AsyncAPI, GraphQL SDL, MCP server,
  or A2A agent card exists at any probed location on www.odaseva.com, api.odaseva.com,
  platform.odaseva.com or trust.odaseva.com.
- The Odaseva Platform API is real but customer-gated: api.odaseva.com answers HTTP 401 to every
  unauthenticated request, and the customer knowledge base sits behind the platform login.
- The one publicly installable client is the first-party Odaseva CLI on npm, last released
  2022-12-09.
- Authentication is a Salesforce-platform OAuth 2.0 / OIDC login (issuer
  https://login.salesforce.com) plus an Odaseva username/password to access-token exchange in
  the CLI. No API keys.

## Client tooling

- [odaseva-cli](https://www.npmjs.com/package/odaseva-cli): first-party CLI, "Command line interface to Odaseva Platform" (v2022.12.0, published 2022-12-09). Commands cover login/logins/active/current, apiVersion, org register/list/info/delete, backup, backup upload, restore, job list/info/run/clone/retry/delete/download/logs, data, compare data, transform data, metadata retrieve/upload, compare metadata.
- [odaseva-sfdx](https://www.npmjs.com/package/odaseva-sfdx): Salesforce CLI plugin, v1.0.7 (2019-03-14).
- [odaseva-dx](https://www.npmjs.com/package/odaseva-dx): Salesforce CLI plugin, v0.0.0 (2019-08-01); its declared GitHub repo now 404s.
- No server-side SDK exists on npm, PyPI, RubyGems, crates.io, Packagist, Maven Central, NuGet or pkg.go.dev.
